🔄 Automático: se o servidor reiniciar e a URL mudar, o sistema envia o novo link automaticamente por email para todos os colaboradores que ainda não responderam. Você não precisa fazer nada.
📧 Configuração de E-mail

Configure o Gmail que será usado para enviar os convites diretamente da plataforma, com o visual profissional AXIS (logo, botão, cores).

Para criar: myaccount.google.com/apppasswords → App: "Outro" → Nome: "AXIS NR-1" → Copie a senha gerada
🔒 Segurança

• A senha de app é armazenada somente no computador local (arquivo email-config.json)

• Nunca é enviada para servidores externos

• Use sempre uma Senha de App do Gmail — nunca a senha principal da conta
